# 📱 BudgetMate  
### Privacy-Preserving Automated Personal Finance Tracking System Using SMS Analysis

## 📌 Project Overview
BudgetMate is a mobile-based personal finance management application designed to automatically track users’ income and expenses by analyzing bank SMS notifications. The system focuses on **privacy-first design**, ensuring that all sensitive financial data is stored securely on the user’s device without relying on cloud-based storage.

This application is especially tailored for **Sri Lankan users**, as it supports SMS formats used by local banks—a feature missing in most global budgeting applications.

---

## 🎯 Key Features
- 📩 **Automatic SMS Transaction Detection**  
  Extracts transaction details from bank SMS messages using text processing techniques.

- 🔐 **Privacy-Focused & Secure**  
  All data is stored locally using encrypted SQLite databases. No financial data is uploaded to the cloud.

- 🔑 **Biometric & PIN Authentication**  
  Ensures secure access using fingerprint, face recognition, or PIN login.

- ✍️ **Manual Transaction Entry**  
  Allows users to add or edit transactions manually when needed.

- 📊 **Budgeting & Spending Insights**  
  Provides categorized budgets, summaries, and spending reports.

- ⏰ **Bill Reminders & Alerts**  
  Notifies users about upcoming bill payments and spending limits.

- ⚙️ **Customizable Categories**  
  Users can define and manage their own expense categories.

---

## 🛠️ Technologies Used
- **Frontend:** React Native  
- **Backend Services &Database** Firebase (Authentication & Notifications)  
- **Platform:** Android (Midrange Devices)  
- **Security:** Encryption + Biometric Authentication  

---


## 🎯 Project Objectives
- Automate personal finance tracking using SMS notifications  
- Reduce dependency on manual data entry  
- Ensure user privacy through local encrypted storage  
- Provide meaningful financial insights and budgeting tools  
- Support Sri Lankan banking SMS formats  
- Improve financial awareness and money management  

---

## 👥 Target Users
- Sri Lankan Android smartphone users  
- Individuals who rely on bank SMS alerts  
- Users concerned about financial data privacy  
- People currently managing finances manually
